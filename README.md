# Country Game

Offline-first geopolitical country simulation prototype.

Includes procedural world generation, 60 countries, economy, population, stability, resources, diplomacy, trade, military, wars, technology, intelligence, AI turns, natural-language orders, action limits, events, news/history and JSON saves/import/export.

Open index.html for a basic local run, or import the project into StackBlitz. The core simulation does not require an online AI service.
